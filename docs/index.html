          Workload matrix

          Tasks organized by what the agent has to do

          Instead of reporting by source benchmark, DAREBench groups tasks along two workload dimensions: input modality (text or multimodal) and execution form (single-step, multi-step, or multi-step with tools). Each source benchmark maps to exactly one group. Select a cell to see its sources, scoring modes, an example prompt and the strongest models.
